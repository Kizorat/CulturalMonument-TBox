      Modifica accessibilità

      Solo i monumenti per cui la condizione di accesso non è ancora presente nella base di conoscenza (interrogati con FILTER NOT EXISTS). Scegline uno dalla casella di suggerimento, assegna una condizione e il dato verrà aggiunto al grafo.

        Relazioni di vicinanza

        Una query CONSTRUCT genera nuove triple afi:vicinoA tra i monumenti la cui distanza è inferiore a una soglia. La distanza è calcolata dentro la query (approssimazione equirettangolare sulle coordinate geo:asWKT), non in Python. Scegli la soglia e genera il grafo.

          Verifica di completezza

        «esiste almeno un monumento privo della proprietà scelta?»
        (FILTER NOT EXISTS). Se la risposta è falso, tutti i
        monumenti possiedono quella proprietà.
      
          

      
          
        
          
          
          
        
          
        
          
          
        
          
      
          

      
          
    
          
  
          

  
          
    
          
      
          Arricchimento via web
          
      
          
        Partendo da una risorsa della nostra base di conoscenza, una query
        DESCRIBE eseguita sull'endpoint pubblico DBpedia
        recupera dal web le risorse ad essa collegate e ne costruisce un nuovo
        grafo. Il vocabolario schema.org classifica l'entità
        (schema:Library, schema:Organization…) e la collega alle
        risorse che parlano di esso: pagina Wikipedia, sito ufficiale, immagini, categorie.
